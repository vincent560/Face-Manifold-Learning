# AI 人臉影像降維與視覺化分析 (Isomap & Eigenfaces)

本專案探討高維度影像數據在降維過程中的特徵提取與空間分佈。透過 Python 實作電腦視覺中的經典演算法，將 2914 維的人臉數據映射至低維空間。

## 🧠 技術核心與演算法
- **Eigenfaces (PCA)**：利用主成分分析提取人臉的核心特徵，將複雜的像素矩陣轉化為具代表性的特徵向量，實現初步降維。
- **Isomap (流形學習)**：針對非線性分佈的影像數據，利用測地線距離 (Geodesic distance) 保持資料在流形上的結構，成功將影像特徵視覺化於 2D 座標平面。

## 📊 實驗亮點
- **數據預處理**：處理 1348 張人臉影像（尺寸 62x47），完成矩陣正規化與標準化。
- **視覺化洞察**：透過 Isomap 降維圖，可以觀察到影像在旋轉角度、表情變化上的聚類趨勢。
- **重建驗證**：展示了從 150 維特徵空間重構回原始影像的結果，驗證了降維過程中的資訊保留完整度。
